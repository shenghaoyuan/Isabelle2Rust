# rBPF Baseline Directory

- `src/`: rBPF virtual machine, interpreter, verifier, assembler, and platform backends.
- `assmb/`: assembler crate.
- `cli/`: command-line interface crate.
- `test_utils/`: shared test utilities.
- `tests/`: integration tests and ELF fixtures.
- `benches/`: benchmark programs.
- `examples/`: example programs.
- `fuzz/`: fuzzing targets.
- `step_test_fixed/`, `step_test_random/`: instruction-step test crates.
- `doc/`: bytecode documentation.
- `scripts/`: repository maintenance scripts.
- `misc/`: image assets.
- `Cargo.toml`: workspace manifest.
- `LICENSE-APACHE`, `LICENSE-MIT`: upstream licenses.
